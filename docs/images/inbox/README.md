把原始截图直接放这个文件夹（`docs/images/inbox/`）。这里的图片被 `.gitignore` 忽略，不会误提交；
我处理完会把挑中的图复制到 `docs/images/` 并改成正式文件名，再更新 README。

## 命名（6 张，请按此命名后投放）

| 文件名 | 版面 | 主题 |
|---|---|---|
| `reader-inline-light.png` | 上下文对译（原文在上、译文在下） | 亮色 |
| `reader-inline-dark.png` | 上下文对译 | 暗色 |
| `reader-side-by-side-light.png` | 左右双栏 | 亮色 |
| `reader-side-by-side-dark.png` | 左右双栏 | 暗色 |
| `reader-<layout>-light.png` | 第三种的版面（见下） | 亮色 |
| `reader-<layout>-dark.png` | 第三种的版面 | 暗色 |

第三种版面的 `<layout>` 请用下列之一，并把实际用的告诉我就行：

- `target-only`：只显示译文
- `source-only`：只显示原文
- `wide`：加宽/大字号等其他外观

例：第三种若“只显示译文”，文件名就是 `reader-target-only-light.png` 与 `reader-target-only-dark.png`。

## 对图片的要求（能省一次返工）

- 窗口约 1400×900，只含阅读器标签页内容；不要文献库列表或左侧条目面板。
- 标题栏/任务栏若含用户名或本机路径，裁掉。
- 鼠标移出画面；不要悬停、不要选中文字、不要弹窗或气泡。
- 译文必须已全部完成（没有“正在翻译/失败/重试”的块）。
- 同一篇论文、同一位置；目标语言简体中文；默认外观设置。
- PNG（或 PNG 转存），不要二次压缩截图工具的水印。

只放 6 张也可以分批放，我按文件名识别。
